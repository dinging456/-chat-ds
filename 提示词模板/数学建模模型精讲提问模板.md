# 数学建模模型精讲 · 通用提问模板

> 用法：把【】里的内容换成你自己的，其余原样复制给 AI。换模型只改【模型名称】。

---

## 一、懒人版（直接复制这一段就够用）

```
【D:\gptchat数学建模\第2讲 层次分析法】

请把上面这个文件夹里的所有文件（PDF、PPT、代码、论文、Excel 都算）完整读一遍，
然后作为一位资深数学建模教练，用深入浅出的语言教我【层次分析法】这个模型。
我是数学建模小白，不要假设我有任何背景知识，也不要堆术语。

请严格按下面 10 个部分输出：

1. 资料盘点：文件夹里有哪些内容，分别是干什么用的
2. 它解决什么问题：适用场景、不适用场景、比赛里常见用法
3. 原理：为什么这样做有效，先讲直觉再落公式
4. 操作流程：分步骤，每步的输入和产出是什么
5. Python 代码：可直接运行、有中文注释、附上真实运行结果
6. 论文要素：需要哪些插图、哪些表格、哪些公式（公式给 LaTeX）
7. 重点分析过程：阅卷老师真正看重的部分是什么
8. 中英文对照：每个环节的中文表述 + 地道英文表述
9. 常见坑：新手最容易犯的错误
10. 下一步建议：我接下来该动手做什么

额外要求：
- 必须用一个具体的小例子把算法走一遍，数字要能让我手算验证
- 讲原理时要说清"这一步为什么存在"，不要只给结论
- 如果资料里的代码、表格、公式有互相矛盾的地方，请直接指出来
- 不要照抄资料原文，请重新组织
```

## 二、完整版（需要更精细控制时用）

```
## 角色
你是一位带过多年国赛的资深数学建模教练，同时很擅长把复杂模型讲给零基础的学生。

## 我的情况
我是数学建模小白，只会基础 Python，没学过运筹学。
我要学的是【层次分析法】，最终目的是能自己写进比赛论文里。

## 资料
文件夹：【D:\gptchat数学建模\第2讲 层次分析法】
请先把它完整读一遍（PDF/PPT/代码/范文/Excel 全部），并在开头用三五句话说明
每份材料的作用，以及它们之间是什么关系。

## 任务
1. 教我这个模型：它解决什么问题、怎么解决、原理是什么
2. 给我能跑通的 Python 代码，并附真实运行结果
3. 告诉我论文里要放什么图、什么表、什么公式
4. 告诉我哪些分析过程是阅卷老师真正看重的
5. 把这部分内容的中文表述和地道英文表述都写出来，让我能直接改用

## 输出格式（严格按此顺序）
1. 资料盘点
2. 它解决什么问题（含"什么情况下别用它"）
3. 原理：直觉解释 → 数学表达 → 为什么有效
4. 操作流程（分步，每步说明输入/输出）
5. Python 代码（可运行 + 注释 + 运行结果 + 如何改成我的数据）
6. 论文要素清单
   - 插图：每张图画什么、放在哪一节、为什么要有
   - 表格：每张表放什么数据
   - 公式：按出现顺序给出，附 LaTeX
7. 重点分析过程（按重要性排序，说明为什么重要）
8. 中英文对照表述（分摘要 / 建模 / 求解 / 结果分析 / 模型评价五段）
9. 常见坑
10. 下一步行动建议

## 质量要求
- 用一个数字干净的小例子贯穿讲解，让我能手算核对
- 每个公式都要有一句"它在干什么"的白话解释
- 涉及数字计算的地方，结果必须准确，必要时实际运行代码验证
- 英文表述要地道（符合学术论文习惯），不要中式英语
- 指出原始资料中可能误导我的地方（例如不同教材参数不一致）
```

## 三、追问模板（看不懂时怎么继续问）

```
（1）我没看懂第【3】部分的【为什么最大特征向量就是权重】，请换一个更简单的
     说法，并且用一个只有 2 个或 3 个元素的例子重新讲一遍。

（2）请把【层次总排序】这一段，按"我该在论文里写哪几句话"的形式帮我写出来，
     中文一遍、英文一遍。

（3）我的题目是【题目背景】，评价指标是【指标1、指标2...】，方案是【方案1...】。
     请帮我：设计判断矩阵 → 运行代码 → 给出结论 → 写成论文里的模型建立和求解章节。

（4）请把【第6节的公式】用 LaTeX 重新给我一遍，并按论文顺序编好号。

（5）请指出我下面这段论文文字的问题，并改写：
     【粘贴你的文字】
```

## 四、换模型时的替换规则

| 位置 | 替换成 |
|---|---|
| 【文件夹路径】 | 哪一讲的资料文件夹 |
| 【模型名称】 | 层次分析法 / TOPSIS / 熵权法 / 灰色预测 / 主成分分析…… |
| 第 5 部分 | 若该模型更适合 MATLAB/R，可改成"用 MATLAB 怎么写" |
| 第 8 部分 | 若不需要英文，可删掉，但建议保留（英文摘要常用得上） |
